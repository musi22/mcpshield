# 🚀 MCPShield Distribution & Marketing Launch Kit

This kit contains ready-to-use, formatted launch copy, social threads, community posts, and PR templates to market **MCPShield** across the developer and AI ecosystem.

| Channel | File | Description |
| :--- | :--- | :--- |
| **Hacker News** | [`HACKER_NEWS_SHOW_HN.md`](HACKER_NEWS_SHOW_HN.md) | Ready-to-post "Show HN" submission and introductory comment. |
| **Reddit** | [`REDDIT_POSTS.md`](REDDIT_POSTS.md) | Tailored posts for `r/ClaudeAI`, `r/LocalLLaMA`, and `r/netsec`. |

## 📅 Recommended 3-Step Execution:

1. **Step 1:** Submit the PR to [`punkpeye/awesome-mcp-servers`](https://github.com/punkpeye/awesome-mcp-servers) using [`AWESOME_MCP_SUBMISSION.md`](AWESOME_MCP_SUBMISSION.md).
2. **Step 2:** Post on Hacker News using [`HACKER_NEWS_SHOW_HN.md`](HACKER_NEWS_SHOW_HN.md) around 9:00 AM EST (optimal timing for HN).
3. **Step 3:** Post the Twitter thread ([`TWITTER_THREAD.md`](TWITTER_THREAD.md)) and cross-post to `r/ClaudeAI` and `r/LocalLLaMA` ([`REDDIT_POSTS.md`](REDDIT_POSTS.md)).
