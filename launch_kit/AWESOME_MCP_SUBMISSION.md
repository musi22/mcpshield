### PR Description:
```markdown
### Summary
This PR adds [MCPShield](https://github.com/musi22/mcpshield) under the Security / Developer Tools section.

### Description
MCPShield is an open-source (Apache 2.0) reverse proxy and policy engine for Model Context Protocol. It allows developers to enforce deterministic policies on tool arguments (e.g. refund limits, path checks), perform automated DLP/secret redaction, intercept high-risk calls for human approval, and scan MCP servers for 25+ vulnerability classes producing SARIF 2.1.0 output.
```
